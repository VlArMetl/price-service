# price-service

Учебный сервис расчёта базовой цены товаров для доставки продуктов (по мотивам Ozon fresh).

Сервис получает данные о товаре (закупочная цена, цена конкурента, срок годности),
считает базовую цену по правилам и сообщает об изменениях другим сервисам.

**Стек:** Go, PostgreSQL, Redis, Kafka, gRPC, Docker.

## Правила расчёта цены

1. Целевая наценка к закупочной цене (по умолчанию 30%).
2. Если конкурент дешевле, подстраиваемся под него, но не ниже минимальной наценки (10%).
3. Скоропортящийся товар уценяем: за 2 дня до конца срока на 15%, за 1 день на 30%, в последний день на 50%.
4. Цена не меняется больше чем на 20% за один пересчёт (кроме уценки по сроку).
5. Цена округляется до целых рублей. Деньги хранятся в копейках (`int64`), а не во `float64`.

## Запуск

```bash

```
